TRIPTALE ATELIER — VERSIONE ALTERNATIVA PER IPHONE

Questa è una variante sperimentale indipendente della TripTale 1.0 di Claude.

PUBBLICAZIONE:
1. Crea un repository GitHub pubblico, per esempio TripTale-Atelier.
2. Carica nella radice i file contenuti in questo ZIP (non lo ZIP stesso).
3. In Settings > Pages scegli Deploy from a branch, main, / (root).
4. Apri l’indirizzo HTTPS pubblicato da GitHub Pages su Safari dell’iPhone.
5. Tocca Condividi > Aggiungi alla schermata Home.
6. Apri l’icona TripTale Atelier e prova la sezione Libreria.

IMPORTANTE:
- Non aprire index.html come file locale: offline, PWA e foto richiedono HTTPS.
- Questa variante usa le chiavi tt2, quindi NON legge automaticamente i dati di TripTale 1.0 (tt1).
- Il viaggio Sri Lanka è incluso come dati iniziali di esempio personale.
- Non è stata validata su un iPhone reale. Prima di usarla in viaggio, verifica backup, importazione, foto e offline.
- La Libreria organizza i viaggi senza duplicarli; il comando Archivia è reversibile.
- Non sostituire la versione di Claude senza test e backup.
